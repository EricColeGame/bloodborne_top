## ブラッドボーンの物語が最初は理解不能に感じられる理由

ブラッドボーンは答えを手渡してはくれません。腐りかけたヴィクトリア朝の街に放り込まれ、ノコギリ鉈を腕に括りつけられ、ひとつの指示を囁かれるだけです。それは「蒼ざめた血を探せ」。数十時間後、ほとんどのプレイヤーは神を一柱か二柱は殺しているのに、実際に何が起きたのか説明できません。だからこそ、明確な**ブラッドボーンのストーリー解説**が必要なのです。物語はカットシーンではなく、アイテムの説明文、環境の手がかり、そして任意のNPCの会話の中に生きています。

この**ブラッドボーンのストーリー解説**ガイドは、ヤーナムの歴史を順番にたどっていきます。古き血、癒しの教会、狩り、上位者たち、そしてすべてのエンディングまで。ファンフィクションは不要です。ゲームが実際に与えてくれる断片を、筋の通る形に組み上げるだけです。

## 前提：異邦人、病、そして血の上に築かれた街

あなたは部外者です。キャラクターは名もなき病の治療を求めてヤーナムへと旅立ちます。街で有名な「血の施し」——ほとんど何でも治せるらしい医学的奇跡——に惹かれてのことです。あなたは契約書に署名し、輸血を受け、狩りの夜の日没とともに診療所の台の上で目を覚まします。

これが導入であり、意図的に薄っぺらく作られています。それ以外のすべては世界の中に埋められています。ヤーナムはゴシック調のヴィクトリア朝時代の街で、その経済も宗教もすべて血の上に成り立っています。癒しの教会が血を配り、市民がそれを崇拝し、通りはそれを摂りすぎて別の何かに変わってしまった者たちで溢れています。

最初に理解すべきは、ブラッドボーンは街を救う物語ではないということです。これは、文明が自らの生物学的本性から逃れるために何を犠牲にするか——そして、誰かが地面を掘り始める前から街の下に何が生きていたか——を描く物語なのです。

## 背景：ビルゲンワース、古き血、そして癒しの教会

ゲームが始まるずっと前、ビルゲンワースと呼ばれる学術機関がヤーナムの下の遺跡を研究していました。ウィレム師が学園を率い、人類は啓蒙を得ることで進化できると信じていました。文字通り、より多くの目を生やして高次の真理を認識するのです。彼の最も有名な弟子であるローレンスは、別の考えを持っていました。

街の下の迷宮を探検するうちに、上位者と呼ばれる宇宙的存在と接触していた古代文明、プトゥメルの痕跡が発見されました。それらの遺跡とともに現れたのが古き血です。傷を癒し、病を治し、並外れた力を与える物質です。ウィレムの警告——「古き血を恐れよ」——は、この世界全体を定義する思想的対立となりました。

ローレンスはビルゲンワースを去り、癒しの教会を創設して、血の施しを公の聖礼典に変えました。それは機能しました。同時に獣の災いも生み出しました。古き血はただ癒すだけでなく、変容させるからです。プレイヤーが到着する頃には、教会は自らの奇跡がもたらした結果を何世代にもわたって処理してきたのでした。

| 時代 | 主要人物 | 起きたこと |
|---|---|---|
| プトゥメル時代 | ヤーナムの女王、プトゥメル人 | 地下の文明が上位者たちと交流し、ヤーナムの下に迷宮を築いた |
| ビルゲンワース時代 | ウィレム師、ローレンス | 学者たちが遺跡を発掘し、古き血を発見し、その使用をめぐって分裂した |
| 癒しの教会時代 | ローレンス、ルドウィッグ、聖歌隊 | 血の施しが街中に広がり、獣の病が始まり、隠蔽された |
| 長い夜（本編） | プレイヤー、ゲールマン、ミコラーシュ | 狩りが崩壊し、夢と現実世界の境界が崩れていく |

## 狩り、獣たち、そして終わらない夜

ヤーナムは獣の病に、街がネズミ問題に対処するのと同じ方法で立ち向かいます。すなわち、狩人を雇うのです。最初の狩人であるゲールマンは工房の伝統を確立しました。素早い武器、パリィ用の銃、そしてかつての隣人を殺すことを厭わない姿勢です。通常の夜なら、狩人たちは獣を間引き、家に帰ります。

あなたがプレイする夜は通常の夜ではありません。それは延々と続き、月は空の異様な位置に掛かり、街の各派閥がそれぞれの思惑を追い求める中、通りは怪物で埋め尽くされていきます。

| 派閥 | 拠点 | 真の目的 |
|---|---|---|
| ビルゲンワース | ビルゲンワース学園 | 啓蒙と目を通じて進化を達成すること |
| 癒しの教会 | 大聖堂街 | 血の聖礼典を管理し、獣の病を抑え込むこと |
| 聖歌隊 | 大聖堂街上層 | 上位者たちと交信し、研究すること |
| メンシス学派 | メンシスの悪夢 | 儀式的な夢見と接触によって昇華すること |
| 狩人 | 狩人の工房／狩人の夢 | 狩りの最中に獣を間引くこと |
| 穢れた血 | カインハースト城 | 教会の敵として血の力を追求すること |
| 処刑人 | カインハースト遠征 | 穢れた血を完全に殲滅すること |

ひとつのゲームメカニクスが静かに物語を語っています。それは「啓蒙」です。ボスや発見から啓蒙を得るにつれて、世界は変化します。見えなかった生き物が見えるようになり、一部の敵の挙動が変わり、ゲームはすべてが正常であるふりをやめます。コミュニティの報告では、大聖堂街の屋根にアメンドーズが初めて現れる瞬間を、ブラッドボーンの物語が腑に落ちる転換点としてよく挙げます。怪物は最初からそこにいたのです。あなたがそれを認識できなかっただけなのです。

## 上位者たち：狩りの下にある宇宙的真理

上位者たちこそが、このゲームの真の主題です。彼らは古く、強力で、根本的に異質な存在であり、教会が何世代にもわたって接触し、利用し、あるいは複製しようとしてきた者たちです。血は彼らの媒体です。ヤーナムのあらゆる奇跡は、彼らから借りたものです。

物語の決定的な転換点は、虚ろな蜘蛛ロムです。ロムは幕として機能します。ロムが生きている限り、上位者たちの真実は平凡な夜の背後に隠されています。ロムを殺せば血の月が降り、空は赤く染まり、街の秘密が明らかになります。これがゲーム中間のどんでん返しであり、それ以前のすべてを再解釈させる出来事です。

そこから、メンシス学派が焦点となってきます。ミコラーシュと彼の学者たちは儀式的な夢見を通じて上位者たちに到達しようとし、その結果メンシスの悪夢を生み出しました。これは幼き上位者メルゴーの泣き声によって維持される小規模な現実です。一方、『The Old Hunters』DLCの漁村は、別の呪いの起源を明かします。狩人たちが殺した上位者コスの亡骸、そしてそこから生まれた孤児です。

| 上位者 | 遭遇場所 | 物語における役割 |
|---|---|---|
| 月の顕現 | 狩人の夢（最終決戦） | 狩人の夢を創り出し維持する。ゲールマンをそこに縛りつける |
| 虚ろな蜘蛛ロム | 月の湖 | 血の月を覆い隠し、上位者たちの影響を隠す |
| 宇宙の娘エブリタス | 絶望の祭壇 | 聖歌隊が研究し崇拝した、捕らわれの上位者 |
| アメンドーズ | 大聖堂街ほか | 街の建築物にしがみつく、不可視の監視者たち |
| オドン | どこにもいない——形を持たないため | 血の上位者であり、代理の子を延々と求め続ける |
| メルゴー | メンシスの悪夢 | 泣き声が悪夢を維持する幼き上位者 |
| コス（コスム） | 漁村／コスの孤児 | 殺された上位者。その死が村全体を呪った |

これらを結びつける繰り返しのテーマがあります。上位者たちは我が子を失い、代わりを求めるのです。オドンは代理の子を追い、月の顕現は狩人たちを我が物とします。癒しの教会の昇華への執着は、その根底において、養子にしてもらうための試みなのです。

## 3つのエンディングの解説

ブラッドボーンには3つのエンディングがあり、それらはゲームが何を主張しているかを最も明確に示すものです。3つとも、狩人の夢でゲールマンと最後の会話をした後に発生します。

| エンディング | 入手方法 | 意味すること |
|---|---|---|
| ヤーナムの夜明け | ゲールマンの申し出を受け入れる | 現実世界で目を覚ます。あなたにとって狩りは終わるが、ヤーナムは変わらない——あなたはただ逃げ出しただけ |
| 願いを叶える | 申し出を断り、ゲールマンを倒す | ゲールマンに代わって狩人の夢の主となり、同じ循環に囚われる |
| 幼年期の始まり | へその緒の3分の1を少なくとも3つ摂取し、申し出を断り、ゲールマンを倒し、さらに月の顕現を倒す | あなたは幼き上位者となり、素朴な人形があなたを抱きかかえる——人類の次の段階か、あるいはその代替物か |

へその緒は「真の」エンディングへの鍵であり、ゲームは4つを隠しています。必要なのは3つだけです。

| 手順 | やること |
|---|---|
| 1 | 癒しの教会の下にある捨てられた古い工房でへその緒を見つける |
| 2 | イオセフカの診療所と偽医者にまつわるへその緒を入手する |
| 3 | 血の月の後、大聖堂街でアリアンナの子からへその緒を手に入れる |
| 4 | メンシスの悪夢でメルゴーの乳母を倒し、そこにあるへその緒を取る |
| 5 | 最後にゲールマンと話す前に、少なくとも3つのへその緒を摂取する |
| 6 | 申し出を断り、ゲールマンを倒し、さらに月の顕現を倒す |

へその緒を飛ばしたプレイヤーも完全な物語を得られます。ただし、より悲劇的なバージョンを得るだけです。「幼年期の始まり」のエンディングは、主人公が獲物であることをやめる唯一のエンディングです。

## 自分で物語を追う方法

要約ではなく実際に物語を体験したいなら、いくつかの習慣が大きな違いを生みます。

- **拾ったアイテムの説明文をすべて読む。** 武器、ルーン、そして特に「へその緒の3分の1」の項目には、カットシーンが省いた伝承が込められています。
- **NPCと何度も話し、再訪する。** 主要ボスの後で会話が変わり、何人かのキャラクターは血の月の後にしかその目的を明かしません。
- **啓蒙のカウンターを注視する。** 啓蒙が高いほど見えるもの、聞こえるものが変わり、一部の遭遇は高い閾値でのみ意味を持ちます。
- **任意エリアを回る。** カインハースト、大聖堂街上層、そして『The Old Hunters』DLCには、物語への最も直接的な答えが含まれています。
- **夢と現実世界を区別して追う。** 狩人の夢が上位者によって創られた別の現実だと受け入れれば、混乱の多くは解消します。

ゲームそのものについては、公式の[PlayStationのブラッドボーンページ](https://www.playstation.com/en-us/games/bloodborne/)が発売に関する信頼できる情報源であり続けており、フロム・ソフトウェアの2015年のPlayStation 4タイトルが依然として唯一のバージョンです。リマスターは発表されていません。

ひとつ注意を。ネット上で見つかる「伝承」の多くは、事実として提示されたコミュニティの解釈です。蒼ざめた血の指示、オドンの正確な性質、そして「幼年期の始まり」のエンディングの究極の意味は、テキスト上はすべて本当に曖昧です。それらについて自信たっぷりに語られる答えは、プレイヤーの体験として扱い、カノンとはみなさないようにしてください。

## FAQ

**ブラッドボーンの物語はゲーム本編のどこかで説明されていますか？**
直接的には説明されていません。コードやナレーターは存在しません。物語はアイテムの説明文、環境デザイン、NPCの会話、そして上位者たちを理解して初めて意味を持つ3つのエンディングを通じて届けられます。このような**ブラッドボーンのストーリー解説**ガイドは、本質的に翻訳レイヤーのようなものです。

**「蒼ざめた血を探せ」は実際に何を意味するのですか？**
意図的に未解決のままにされています。そのメモは冒頭に現れ、はっきりとは説明されません。コミュニティの解釈は、蒼ざめた血が月の顕現を意味するという説から、上位者たちの蒼ざめた血を指すという説、さらには狩りそのものを超越せよという指示だという説まで幅広くあります。ゲームは3つすべての読みを支持しています。

**ブラッドボーンを理解するためにダークソウルをプレイする必要はありますか？**
いいえ。ブラッドボーンはフロム・ソフトウェアのデザイン哲学を共有していますが、連続性は共有していません。独自の宇宙論を持つ独立した世界であり、ダークソウルから持ち越されるものは何もありません。

**どのエンディングがカノンですか？**
公式のカノンはありません。「幼年期の始まり」は、最も手間がかかりへその緒を必要とするため「真の」エンディングとして広く扱われていますが、フロム・ソフトウェアは正史となる結末を確認したことはありません。3つすべてが物語の正当な結末です。

**なぜ上位者たちはプレイヤーの前に現れ続けるのですか？**
プレイヤーが啓蒙を得続けるからです。このゲームの中心的な恐怖は知覚に関するものです。上位者たちは最初からそこにいて、狩り、血、そして教会の聖礼典が、徐々にあなたを彼らを見ることができる存在へと変えていったのです。
