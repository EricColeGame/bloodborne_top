## なぜブラッドボーンの装束セットは新米狩人を混乱させるのか

ブラッドボーンの装束セットは、本作で最も誤解されている装備です。ほとんどのプレイヤーは最初の1時間で気に入った見た目を見つけ、それを装備して二度と装束メニューを開きません——それは間違いです。ポイズと装備重量の計算問題だったダークソウルとは異なり、ヤーナムの服は状況に応じた道具一式であり、適切なブラッドボーンの装束セットは、冬のランタンの視線を生き延びるか、ランプに戻って目覚めるかの差になります。

良い知らせは、このシステムが見た目よりずっと単純だということです。装備重量も重量ペナルティもなく、服の強化ルートもありません。鍛冶屋に触れることなく狩りの途中で一式を交換できるので、賢い狩人は装束をゴルフバッグのように扱います。コースに合うクラブを選ぶのです。

## ブラッドボーンの装束セットの実際の仕組み

装束は4つのスロットに装備され、各部位が独自の防御値と耐性を持っています。セットは見た目とおおよそ似たステータス構成を共有しますが、教会のフードと狩人のズボンを混ぜることを妨げるものはありません——数字を理解すれば、おそらくそうするでしょう。

ゲーム内メニューでは2つのカテゴリを追跡します。**防御**は特定のダメージタイプによるダメージを軽減します。**耐性**は状態異常の蓄積を軽減します。どちらも単独では劇的ではありません。ある戦闘における「良い」セットと「悪い」セットの差は、たいてい数パーセントです。しかしそのポイントは4部位で積み重なり、冬のランタンにつかまれた一度で探索が終わりうるゲームでは、重要になります。

| スロット | 対象 | 装束の例 |
|---|---|---|
| 頭 | 帽子、フード、兜、檻 | 狩人帽子、メンシスの檻、幻影の王冠 |
| 胴 | コート、ローブ、ドレス、チュニック | 狩人装束、聖歌隊装束、貴族のドレス |
| 腕 | 手袋、籠手、包帯 | 狩人手袋、処刑人の籠手 |
| 脚 | ズボン、ブーツ、スカート | 狩人ズボン、アリアンナの靴 |

特筆すべき点がひとつあります。装束棚の項目のうちいくつかは、一式ではなく単品です。アリアンナの靴、幻影の王冠、メンシスの檻、肥大した頭部はすべて単品アイテムなので、目にするすべての名前に揃った4部位があるとは期待しないでください。

### ステータス早見表

集め始める前に、何を求めて選ぶのかを知っておくと役立ちます。装束に表示されるすべての数値の短縮版です。

| ステータス | 軽減するもの | 役立つ場面 |
|---|---|---|
| 物理 | 標準的な武器や爪のダメージ | すべての戦闘——基本となるステータス |
| 打撃 | 棍棒、ハンマー、獣の重い薙ぎ払い | レンガのトロル、教会の巨人、獣の群れ |
| 刺突 | 貫通攻撃や突進 | プスメリアの敵、レイピア使いの狩人 |
| 血 | 血質攻撃 | カインハーストの狩人、血に飢えた獣 |
| 神秘 | 神秘ダメージ | エブリエタス、ロマ、上層聖堂街 |
| 炎 | 炎ダメージ | 旧市街、ローレンス、古王の番犬 |
| 雷 | 雷ダメージ | 暗黒獣パール、ヤハグィル |
| 遅効毒 | 徐々に蓄積する毒 | 毒の湖、禁断の森 |
| 劇毒 | 素早く爆発する毒 | 一部の敵と聖杯ボス |
| 発狂 | 発狂の蓄積 | 冬のランタン、メンシスの悪夢 |
| 獣性 | 防御ではなく、獣性の上限を上げる | 獣の爪や獣血の丸薬を使うビルド |

最後の行こそ、多くの人が見落とすものです。装束の獣性は何かから守ってくれるわけではありません。獣性ゲージの上限と、どれだけ早く溜まるかを上げます。獣の爪ビルドを組んでいる、あるいは獣血の丸薬に頼っているなら、獣性の高い装束は実質的にダメージアイテムです。

単一の「最高」の装束は存在せず、だからこそ装束棚はこれほど奥深いのです。本編だけでも約30の装束項目があり、The Old Huntersでさらに9つ追加されます。実際の場面で際立つものを整理するとこうなります。

|---|---|---|
| カラス羽の装束 | 一般的なプレイ、血質ビルド、ファッション | バランスの取れた防御と、ヤーナムで最も印象的なシルエット |

| ヤハグィル装束（フードまたは兜） | 雷ダメージと中盤の探索 | 雷対策を備えたバランスの良い防御；頭部が2種類 |

プレイヤーの経験は、シンプルなルールに収束しがちです。既定ではカラス羽か狩人装束を着て、これから向かう地域に合わせて炎、神秘、雷、発狂の部位に交換する。あなたが想像しているフルセットボーナスは存在しません——揃った装束は見た目の統一感であり、隠し倍率ではないのです。

## 主要なブラッドボーン装束セットの入手場所

新米狩人が詰まるのは入手の部分です。装束は6、7種類の異なる経路から手に入り、どれもラベルが付いていません。以下がその地図です。

| 入手源 | 仕組み | この経路で手に入るセット |

| 浴槽の使者（血の反響） | 狩人の夢で血の反響を使って購入 | 序盤の狩人装束といくつかの基本装備 |
| 浴槽の使者（洞察） | 洞察を得ると2つ目のショップが解放 | ガスコイン装束、ヘンリック装束、その他のボス関連セット |

| 現地入手 | 特定地域の死体や宝箱 | 焦げた狩人装束、騎士装束、カインハースト装束、聖歌隊装束、学生装束、ヤハグィル装束 |
| 聖杯ダンジョン | 深度探索とボーナス部屋 | 墓探し装束、墓守装束 |
| The Old Hunters | DLC地域とDLCボス | 次のセクションを参照 |

実用的なコツとして、主要ボスを倒すたびに浴槽の使者の両ショップを確認しましょう。いくつかのセットは特定の撃破後でないと洞察ショップに現れず、ゲームはそれを教えてくれません。名前付きの狩人やストーリーボスを倒しても新しいものがない場合は、次のボス後に戻ってきてください——在庫は段階的に更新されます。

ゲームと拡張版の公式な概要については、[PlayStation.comのBloodborne公式ページ](https://www.playstation.com/en-us/games/bloodborne/)が各バージョンの収録内容を確認するうえで最も信頼できる資料です。

## 装束棚を整える実践的なコツ

すべてのセットを農場で集める必要はありません。必要なのは対応範囲です。効率的にそこへ到達する方法を紹介します。

- **「コレクション」ではなく「対応キット」を作る。** 物理、炎、神秘／発狂、雷の4つの装束があれば、ゲーム内の遭遇のおよそ90％に対応できます。
- **発狂耐性は最も過小評価されているステータス。** 冬のランタンとメンシスの悪夢は、装束が本当に命を救う2つの場所です。行く前に発狂耐性を積みましょう。
- **打撃と刺突を怠らない。** 獣型の敵は大きく重く振り回し、教会型の敵は突きます。物理防御だけでは両方に対応できません。
- **部位は自由に混ぜる。** ある胴部位が優れた炎防御を持っているのに脚が見苦しいなら、別セットの見苦しい脚を履きましょう。何のペナルティもありません。
- **交換はランプで、戦闘中ではなく。** 装束の変更はインベントリ内で即座にできますが、狩人に突進されている最中に行うのは悪手です。
- **ボスごとに洞察ショップを確認。** いくつかのブラッドボーン装束セットは、ショップが黙って在庫補充されるために、永久に取り逃しそうに感じられるだけです。

| 遭遇 | 対策すべきダメージ | 役立つ装束 |
|---|---|---|
| 冬のランタン、メンシスの悪夢 | 発狂 | 所持している中で最も発狂耐性の高い部位 |
| ローレンス、古王の番犬 | 炎 | 焦げた狩人装束 |
| 暗黒獣パール、ヤハグィル | 雷 | ヤハグィル装束 |
| エブリエタス、白痴の蜘蛛ロマ | 神秘 | 聖歌隊装束 |
| カインハーストの狩人 | 血 | 騎士装束 |
| 毒の湖、禁断の森 | 遅効毒 | 遅効毒耐性の高い部位 |

## よくある質問

**ブラッドボーンの装束セットにセットボーナスはありますか？**
いいえ。4部位を揃えても、一貫した見た目と似たステータス構成以上は得られません。唯一の「ボーナス」は、揃ったセットが耐性のテーマを共有しがちで便利ということです。

**ブラッドボーンで装束を強化できますか？**
いいえ。装束は血の石の欠片などで強化できません。見つけたものがすべてで、だからこそ部位を自由に交換するのが想定されたプレイスタイルです。

**初心者におすすめのブラッドボーン装束セットは？**
まず狩人装束かカラス羽の装束で一般的な物理防御を確保し、旧市街とローレンスの前に焦げた狩人装束を入手しましょう。この3つで序盤から中盤の大半をカバーできます。

**装束の重量や装備重量は関係ありますか？**
まったくありません。重量システムもスタミナペナルティも、重そうな服による移動ペナルティもありません。必要な耐性が得られるものを着る——あるいはこのスタイリッシュなゲームでは正当な戦略である、一番かっこいいものを着るのです。

結局のところ、ブラッドボーンの装束セットは装束棚に偽装した道具一式です。各戦闘が求めるステータスを学び、4つの装束を用意しておけば、状態異常で死ぬ時間が減り、狩りを楽しむ時間が増えるでしょう。
