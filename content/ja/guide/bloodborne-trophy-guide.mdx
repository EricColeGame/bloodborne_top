ブラッドボーンは昔ながらの方法でプラチナを差し出してきます。つまり、稼がせるのです。3つの排他的なエンディング、クエストラインを逃すと容赦なく響く武器リスト、体力バーを半減させる聖杯ダンジョン——プラチナは反射神経のテストというより、計画性のテストです。だからこそ優れた**ブラッドボーン トロフィーガイド**が重要なのです。何を先にやるべきか、何が二度と取り返せないのか、そして不要な3周目をどう避けるかを教えてくれます。

この**ブラッドボーン トロフィーガイド**は、ひとつの考え方を軸にしています。ロックアウトにつながる決断はすべて前倒しで処理し、作業的な稼ぎは後回しにする。そうすればプラチナは、New Game Plusでのイライラする後片付けではなく、長くてもスムーズな狩りになります。

## ブラッドボーン トロフィーガイドの概要

キャラクターを作る前に、何に手を出すのかを把握しましょう。以下の数値は、トロフィー攻略サイトのコミュニティの総意と、本編を通したプレイヤー経験を反映したものです。

| 項目 | 目安 |
|---|---|
| プラチナ難易度 | 10段階中6程度（コミュニティの総意） |
| 推定クリア時間 | 約50〜80時間 |
| 最低プレイ周回数 | セーブをバックアップすれば1周、しなければ3周 |
| 取り逃しトロフィー | あり — NPCクエストライン、へその緒、エンディング |
| 難易度設定 | なし。ゲームはあるがまま |
| オンライントロフィー | 本編にはなし |
| DLC | 『ザ・オールドハンターズ』は独立したトロフィーセット |

「オンライントロフィーなし」というのは純粋に朗報です。プラチナは完全にオフラインで狙えますし、PlayStation Plusが必要なのはボス攻略で協力プレイを求める場合だけです。プラットフォームの詳細は[PlayStation公式のブラッドボーンページ](https://www.playstation.com/en-us/games/bloodborne/)を参照してください。

## ロードマップ：プラチナまでの6フェーズ

やり込み勢はさておき、構造化されたルートを辿るプレイヤーの多くは、1フェーズにつき2〜3回のプレイで完了します。以下の表を旅程表として扱ってください。

| フェーズ | 現在地 | 主要トロフィー | 忘れずに |
|---|---|---|---|
| 1. 序盤のヤーナム | 中央ヤーナム → 大聖堂区 | 聖職者の獣、ガスコイン神父、血に飢えた獣 | アイリーンのクエストラインを開始 |
| 2. 中盤 | 禁じられた森 → ビルゲンワース | ヤーナムの影、ロマ | カインズハーストの招待状を入手 |
| 3. 任意の分岐 | ヘムウィック、カインズハースト、悪夢の辺境 | ヘムウィックの魔女、殉教者ローガリウス、アミグダラ | カインズハーストの武器と装備 |
| 4. 血の月 | ヤハグール → メンシスの悪夢 | 再生者、ミコラーシュ、メルゴーの乳母 | へその緒を回収 |
| 5. 後片付け | 聖杯ダンジョン、大聖堂上層 | プトゥメルの女王、コレクショントロフィー | 獣の爪、狩人の道具 |
| 6. フィナーレ | 狩人の夢 | 3つのエンディングすべて | まずセーブをバックアップ |

フェーズ3は、飛ばして後悔する人が多いところです。カインズハースト城だけでもコレクショントロフィーに関わる武器が複数隠れていますし、カインズハーストへの招待はヘムウィックの墓地通りで発生します。どちらも任意エリアでありながら、コンプ勢には必須の報酬があります。

## 取り逃しトロフィー：取り返しがつかないもの

ブラッドボーンはチェックポイントには寛大で、セカンドチャンスにはケチです。コミュニティの報告では、同じようないくつかの不可逆なミスが繰り返し指摘されています。

| 取り逃し対象 | ロックされる条件 | 回避方法 |
|---|---|---|
| 慈悲の刃（狩人の本質） | アイリーンが死ぬとクエストラインが失敗 | 彼女の狩りを順番にこなし、攻撃しない |
| へその緒（三分の一／アリアンナ） | アリアンナが生存し、オドン教会へ送られている必要あり | イオセフカの診療所には絶対に送らない |
| へその緒（三分の一／イオセフカ） | フィナーレ前のみ到達可能 | 禁じられた森の洞窟から診療所へ入る |
| 幼年期の始まり | ラスボス前にへその緒3本を消費する必要あり | 序盤に確保し、終盤に消費する |
| 3つのエンディングすべて | 既定では1周につき1エンディング | セーブをバックアップ（下記参照） |
| 獣の爪 | 聖杯ダンジョン限定 | 深度4の攻略中に稼ぐ |

ベテランが引っかかるのは、新規プレイヤーではなくアリアンナのへその緒です。彼女が生きていて、教会におり、血の月を越えている必要があります。もし診療所に送ってしまっていたら、その周ではもう手に入りません。

## 3つのエンディングとセーブバックアップの裏技

3つのトロフィーはゲームの3つのエンディングから得られ、1周につき1つしか発生させられません。それぞれの内訳は以下の通りです。

| エンディング | 発生条件 | トロフィー | 必要条件 |
|---|---|---|---|
| ヤーナムの夜明け | ゲールマンの申し出を承諾 | ヤーナムの夜明け | なし — 最速ルート |
| 願いを叶えて | 拒否し、ゲールマンを撃破 | 願いを叶えて | 最初の狩人を倒す |
| 幼年期の始まり | へその緒を3本消費して拒否、ゲールマンと月の魔物を撃破 | 幼年期の始まり | へその緒3本 |

1周ですべてを取るには、ゲールマンと話す前にセーブをPlayStation PlusのクラウドストレージかUSBドライブにバックアップし、各エンディング後に復元します。先に自動アップロードをオフにしてください。そうしないとクレジットが流れた瞬間にバックアップが上書きされます。

コミュニティの報告によれば、この裏技は3周分のフルプレイと比べて15〜20時間を節約できます。読む価値のあるブラッドボーン トロフィーガイドなら、まずこれが最大のショートカットです。

## コレクショントロフィー：武器、道具、血晶、ルーン

ここが、カジュアルなプラチナと作業感の強いプラチナを分けるトロフィー群です。難しいものはひとつもなく、すべては帳簿付けです。

| トロフィー | 条件 | 本当の障害 |
|---|---|---|
| 狩人の本質 | 本編のすべての変形武器と火器 | アイリーンの慈悲の刃、カインズハーストの装備、獣の爪 |
| 狩人の工芸 | 狩人の道具9種すべて | 彼方からの呼び声と聖歌隊の鐘は見逃しやすい |
| 血晶マスター | 最上級の血晶 | 深層聖杯での血晶稼ぎ |
| ボストロフィー | 主要ボスと任意ボス各1体につき1つ | エブリタスや殉教者ローガリウスなどの任意ボス |

狩人の道具9種は、獣の咆哮、空の幻想殻、古い狩人の骨、小さな雷、エブリタスの予兆、処刑人の手袋、使者の贈り物、聖歌隊の鐘、彼方からの呼び声です。進めながらチェックしていきましょう。1つのアイテムのために大聖堂上層を引き返すのは、誰にとっても楽しいものではありません。

武器については、紙のチェックリストを用意してください。いくつかは特定のバッジを獲得した後に浴槽の使者が売り出すものなので、主要ボスを倒すたびに狩人の夢のショップを訪れ、新商品があれば買っておきましょう。

## 聖杯ダンジョンのトロフィーと冒涜の難所

プトゥメルの女王のトロフィーは聖杯ダンジョン連鎖の最下層にあり、ゲーム中最長の単一の稼ぎ作業です。クリティカルパスは次の通りです。

| 深度 | 聖杯 | ここに来る理由 |
|---|---|---|
| 1 | プトゥメル | 連鎖を解放し、形式を学ぶ |
| 2 | 中央プトゥメル | 素材と儀式の血 |
| 3 | 下層プトゥメル | 深度4への入口 |
| 4 | 病みロラン | ロランの落とし子の素材、獣の爪 |
| 4 | 冒涜の聖杯 | 必須 — そして過酷 |
| 5 | プトゥメル・イヒル | ヤーナム、プトゥメルの女王 |

冒涜の聖杯は最大HPを半減させるため、通常なら対処可能なボスが一撃必殺の悪夢に変わります。多くのプレイヤーがぶつかる壁は古き王たちの番犬とアミグダラの2体です。ここでは強引さよりも、忍耐強くヒットアンドアウェイで戦う方が勝ります。

実用的な注意点が2つあります。隠し墓は女王につながらない任意の分岐であり、聖杯ダンジョンはNew Game Plusでスケールしないため、いつでも挑戦できます。多くのプレイヤーはキャラクターを完成させたメインストーリー後に回しています。

## 時間を節約する習慣

- **アイテムの説明文を読む。** ブラッドボーンはクエストのトリガーを堂々と隠しており、へその緒、バッジ、招待状には必ず手がかりが添えられています。
- **NPCとは2回話す。** 多くの会話ツリーは2回目のやり取りでしか進みません。
- **ボスを倒すたびに狩人の夢へ戻る。** ショップの新商品は狩人の本質への前進です。
- **5本を中途半端に強化するより、1本を最大まで強化する。** 血石の塊は1周あたりの入手数が限られています。
- **パリィのタイミングを覚える。** 火器の射撃が決まれば、何時間も奪われるボストロフィーがあっさり片付きます。
- **聖杯の稼ぎはオフラインで** 侵入に邪魔されているなら。トロフィーリストに他プレイヤーを必要とするものはありません。

プレイヤーの経験はほぼ一致して、ある点を指摘しています。プラチナはその評判よりずっと簡単だということです。ブラッドボーンは生のスキルよりも準備に報いるゲームであり、計画されたルートは苦痛のほとんどを取り除いてくれます。

## FAQ

**ブラッドボーン トロフィーガイド通りの攻略は実際どれくらいかかりますか？**
コミュニティの報告の多くは、本編プラチナで50〜80時間の間に収まります。任意ボスや冒涜の聖杯でどれだけ苦戦するかによります。

**1周で3つのエンディングをすべて解除できますか？**
はい。ゲールマンと話す前にセーブをバックアップし、各エンディング後に復元してください。バックアップが残るよう、先にクラウドの自動アップロードをオフにしましょう。

**プラチナにPlayStation Plusは必要ですか？**
いいえ。本編にオンライントロフィーはありません。Plusが役立つのは、手強いボスで召喚の助けを求める場合だけです。

**聖杯ダンジョンのトロフィーは必須ですか？**
プトゥメルの女王のトロフィーはプラチナに必須なので、はい。最低でもプトゥメル・イヒルをクリアする必要があります。このブラッドボーン トロフィーガイドの順序に従えば、その稼ぎが最後の最後で進行を止めることはありません。
