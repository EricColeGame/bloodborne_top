ヤーナムは忍耐を報い、行き当たりばったりを罰する。だからこそ、信頼できる**『Bloodborne』攻略**は反射神経以上に価値がある。通りは警告もなく分岐し、ランタンは少なく、ひとつショートカットを逃すだけで5分の道のりが20分の死体行進になり得る。この**『Bloodborne』攻略**では、狩りを消化しやすい区切り——メインルート、任意エリア、ボス対策、そして全体をつなぐショートカット——に分けて解説する。だから夜の時間は後戻りではなく前進に使える。

ここでは意図的にネタバレを控えめにしている。進行順の指針、ボスのパターン、リソースの優先順位は示すが、分刻みの台本はない。このバランスは重要だ。Bloodborneは未探索の路地に漂う緊張を感じているときが最高で、レベルが4時間分足りないまま終盤エリアに迷い込むときが最悪だからだ。

## ヤーナムへ踏み込む前に：数時間を節約する準備

最初の30分が、その後のプレイ全体の快適さを決める。実際に振り回したい武器に合った出自を選び、序盤の血の遺志は攻撃力より生存力に使おう。体力バーが大きいほうが、攻撃力の数ポイントよりも多くのミスを許してくれる。

| 出自 | 際立った特徴 | 向いているプレイヤー |
|---|---|---|
| 気弱な性格 | 全能力が平均的 | 初回プレイや柔軟なビルド |
| 孤独な生存者 | 初期体力が高い | 余裕を持ちたい新米狩人 |
| 暴力的な過去 | 筋力が高い | 斧や重い仕掛け武器のビルド |
| 退役軍人 | 筋力とそこそこの体力 | 素直な近接殴りビルド |
| プロフェッショナル | 技量が高い | 仕込み杖使いや内臓攻撃重視のプレイ |
| 不幸な幼少期 | 神秘寄り | 狩人道具を早めに使いたい人 |
| 貴族の子弟 | 技量と血質 | 技量/銃のハイブリッドビルド |
| 残酷な運命 | 神秘と血質 | じっくり育てるハイブリッド構成 |
| 役立たず | 初期能力が最低 | 難しい序盤を求めるベテラン |

初期武器も同じくらい重要だ。ノコギリ鉈は変形後の攻撃が速く、獣へのボーナスダメージもあるため、最初の一本として最も扱いやすい。狩人の斧は速度と引き換えにリーチと、集団をなぎ倒す溜め回転斬りを得る。仕込み杖は立ち位置を問われるが、3本の中では最も技量の上限が高い。

初めての**『Bloodborne』攻略**プレイにおけるステータス優先順位：

| ステータス | 影響するもの | 妥当な停止目安 |
|---|---|---|
| 体力 | HP | 序盤30、終盤40〜50 |
| 持久力 | スタミナ | ほとんどのビルドで20〜25で十分 |
| 筋力 | 重い武器と仕掛け武器のスケーリング | 25、本格的に振るなら50 |
| 技量 | 速い武器と内臓攻撃ダメージ | 25、本格的に振るなら50 |
| 血質 | 銃器と血の武器のダメージ | それを軸にする場合のみ |
| 神秘 | 狩人道具と属性血晶 | 道具重視なら25〜40 |

すぐに身につけるべき習慣は3つ。見つけたランタンはすべて灯すこと、余った遺志は溜め込まずに血の瓶と水銀弾に変えること、そして安全に離脱するために大胆な狩人の印を常に携帯することだ。また、狩人の夢にある啓蒙の浴槽の使者で啓蒙を使おう。溜め込むと発狂耐性は上がるが、特定の戦いでは余計なトラブルを招く。

## メインルート：ネタバレ控えめの『Bloodborne』攻略順

クリティカルパスは見た目より短い。行き詰まったと感じるプレイヤーの多くは迷っているのではなく、単に1つの門、1つの鍵アイテム、あるいは必須の扉を開く任意ボスを見逃しているだけだ。

| 順番 | エリア | 主要ボス | 得られるもの |
|---|---|---|---|
| 1 | 中央ヤーナム | ガスコイン神父（聖職者の獣は任意） | 最初の本格的なショートカット、オドン礼拝堂へのアクセス |
| 2 | 大聖堂地区 | アメリア主教 | 合言葉の扉、ルーンへのアクセス |
| 3 | 旧市街 | 血に飢えた獣 | 聖杯の儀式素材、大聖堂の門へのルート |
| 4 | ヘムウィックの墓地 | ヘムウィックの魔女 | ルーン工房の道具 |
| 5 | 禁断の森 | ヤーナムの影 | ビルゲンワースへの道、カインハーストへのルート |
| 6 | ビルゲンワース | 白痴蜘蛛ロマ | 世界状態の変化、敵の行動変化 |
| 7 | ヤハグィル、不可視の村 | 再誕者 | 大聖堂上層の鍵 |
| 8 | メンシスの悪夢 | ミコラーシュ、メルゴーの乳母 | 終盤へのアクセス |
| 9 | 狩人の夢 | ゲールマン、月の魔物 | スタッフロール |

時間を大きく節約する構造上の注意が2つある。第一に、浴槽の使者で10,000遺志を払って狩人の長の紋章を買えば、旧市街に触れずに大聖堂地区の門を開けられる——ただし旧市街を攻略するほうが安上がりで、学べることも多い。第二に、ロマを倒すとヤーナムは永久に変化する。新しい敵が現れ、古いルートが変わり、いくつかのNPCクエストラインは準備ができていなくても進行する。月見湖に飛び込む前に、買い物と任意のサイドコンテンツを済ませておこう。

## 攻略のためのボス別メモ

Bloodborneのボスはどれも、怪物の衣装をまとったパズルだ。以下の表では、多くのプレイヤーがぶつかる壁と実践的な答えをまとめる。

| ボス | 場所 | よくある停滞 | 実践的な答え |
|---|---|---|---|
| 聖職者の獣 | 大橋 | 広い薙ぎ払いとカメラワークの混乱 | 脚元に張り付き、油＋火炎瓶を使い、ロックオンを避ける |
| ガスコイン神父 | オドンの墓 | 容赦ない攻撃性、獣化フェーズ | 人間フェーズはパリィ、オルゴールを使い、墓石周りで戦う |
| 血に飢えた獣 | 旧市街 | 毒の蓄積 | 解毒薬を持ち、血の香るカクテルを使い、火の紙を塗る |
| アメリア主教 | 大聖堂 | 自己回復 | 麻痺の霧を投げ、四肢を破壊し、側面に張り付く |
| ヘムウィックの魔女 | ヘムウィックの墓地 | 見えない標的 | 入る前に啓蒙を下げるか、光る目を探す |
| ヤーナムの影 | 禁断の森 | 3対1の圧力 | 大きな墓石で分断し、術師を最初に倒す |
| 白痴蜘蛛ロマ | 月見湖 | 子蜘蛛の群れ | 追加敵を波ごとに処理し、雷の紙を塗り、神秘の雨を避ける |
| 再誕者 | ヤハグィル | 絶え間ない範囲ダメージ | バルコニーに登り、鐘を鳴らす者を先に黙らせる |
| ミコラーシュ | メンシスの悪夢 | 終わらない追いかけっこ | 毒ナイフと近距離維持で早期に終わる |
| メルゴーの乳母 | メンシスの悪夢 | 暗闇フェーズ | 分身攻撃を回避し、紫の霧の後に反撃 |
| ゲールマン | 狩人の夢 | 高速の大鎌コンボ | パリィ可能——タイミングを覚え、内臓攻撃で罰を与える |

真の最終ボスについての注意：狩りを終える前に第三のへその緒を3つ使用した場合のみ、月の魔物が現れる。コミュニティの報告では、これがゲーム内で最も見逃されやすいエンディング条件として繰り返し挙げられている。へその緒はノートやチェックリストで管理しよう。プレイヤーの経験上、フィナーレ前に任意ボスを倒しておくことも勧められる——追加の遺志と血石の塊があれば、最後の2戦はずっと楽になる。

## 任意エリアと、寄り道する価値がある理由

任意コンテンツを飛ばすのは、終盤で難易度の壁にぶつかる最短の道だ。これらのエリアは強化素材、ルーン、そしてビルド全体を支える固有武器を供給してくれる。

| 任意エリア | 到達方法 | 代表的な報酬 |
|---|---|---|
| 大聖堂上層 | 血の月後にヤハグィルで見つかる鍵 | 血石の塊、エーブリエタース、天上の使者 |
| カインハースト城 | カインハーストの招待状、その後ヘムウィック交叉点の馬車 | 殉教者ローガリウス、血剣、エヴェリン |
| 悪夢の辺境 | 講堂の1階 | アミグダラ、儀式素材、使者の贈り物 |
| 講堂 | ロマ後にアミグダラに掴まれる | アクセス拠点、蜘蛛のパッチ |
| 聖杯ダンジョン | ボスから得る儀式素材 | 血晶、ルーン、ヤーナムの女王 |
| 狩人の悪夢（The Old Hunters） | アメリア後の大聖堂地区の祭壇 | ルドウィッグ、レディ・マリア、コスの孤児 |

このうち2つは、快適な終盤のためにはほぼ必須に近い。大聖堂上層では血石の塊と宇宙の目を見る者の記章が手に入り、カインハーストでは血剣——ほぼ完全に血質でスケールする武器——が手に入る。技量または血質ビルドなら、実際にはこの寄り道は任意ではない。

## ショートカット、ランタン、そして死なない習慣

どんな**『Bloodborne』攻略**でも最も価値のあるスキルは、ショートカットを読み解く力だ。ヤーナムは一連のループとして設計されており、ほぼすべての地区に、長いルートを短縮する門、はしご、エレベーターがある。

- **中央ヤーナム：** 鉈を振るう狩人の近くの家に入り、レバーを引いて最初のランタン横の門を開ける。この1つのショートカットで、以降の挑戦から2分の徒歩が消える。
- **大聖堂地区：** 大聖堂の左にある門は、狩人の長の紋章で開くか、旧市街を攻略して戻ることで開く。
- **禁断の森：** 入口近くのエレベーターで最初のランタンに戻れる。ヤーナムの影戦を覚える間は非常に貴重だ。
- **メンシスの悪夢：** 檻のエレベーターと橋のレバーの両方が、メルゴーの乳母までの道のりを大幅に短縮する。

ショートカット以外にも、快適なプレイとイライラするプレイを分けるリソース管理の習慣が3つある。ボス挑戦前には血の瓶を20個にしておこう。特定のルーンで上限が上がるからだ。ラリーの仕組みは積極的に使う——ダメージを受けた直後に攻撃すると体力の一部が戻り、血の瓶を節約できる。そして、満タンの遺志を抱えたまま新しいエリアに踏み込まないこと。まず狩人の夢でレベル、血の瓶、消耗品に使おう。

ルート順や隠しアイテムについて別の意見が欲しいなら、[IGNの『Bloodborne』攻略ハブ](https://www.ign.com/wikis/bloodborne/Walkthrough) は任意エリアとボス戦略を詳しく扱う、よく整備された参考資料だ。

## よくある質問

**初回プレイに『Bloodborne』攻略は必要ですか？**
厳密には不要だが、軽く参照するだけでも大きな助けになる。このゲームは必須進行を小さな相互作用——鍵アイテム、レバー、NPCとの会話——の裏に隠しており、攻略があれば雰囲気を台無しにせず、何時間もの目的のない徘徊を防げる。

**『Bloodborne』の完全攻略にはどれくらいかかりますか？**
初めての狩人の多くは、クリティカルパスをおよそ30〜40時間でクリアする。任意エリア、カインハースト、大聖堂上層、聖杯ダンジョンを加えると、60時間以上に近づく。

**任意エリアはどの順番で回ればいいですか？**
ルーン工房の道具のためにヘムウィックの墓地を早めに、禁断の森ルートで招待状を手に入れたらカインハースト、ヤハグィルの直後に大聖堂上層。聖杯ダンジョンはストーリー進行よりも血晶稼ぎをしたいときに取っておこう。

**攻略の途中でステータスを振り直せますか？**
いいえ。Bloodborneには振り直しシステムがないので、大きく投資する前にビルドを計画しよう。よくある安全な配分は、体力30、持久力20、主要ダメージステータス25にしてから枝分かれする形だ。

**メインストーリー中にThe Old Huntersをプレイすべきですか？**
DLCは終盤キャラクター向けに調整されている。コミュニティの報告では、十分に強化した武器でレベル70前後以上になってから入るのがよいとされ、多くのプレイヤーは最終ボスの直前に挑戦する。
