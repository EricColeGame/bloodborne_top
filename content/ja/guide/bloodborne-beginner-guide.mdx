ブラッドボーンはPlayStationの中でもっとも報われるゲームのひとつであり、同時に始める際にもっとも容赦のないゲームのひとつでもあります。セントラルヤーナムはためらいを罰し、攻撃性を報い、そしてほとんど何も説明してくれません。だからこそ、しっかりした**ブラッドボーン初心者ガイド**が重要なのです。最初の1時間で投げ出すか、ゲームに夢中になるかの差は、たいていほんのいくつかの小さな習慣で決まります。

この**ブラッドボーン初心者ガイド**では、最初の戦闘の前にやるべきこと、どの生まれと武器を選ぶべきか、戦闘が実際にどう機能するのか、血の残響を賢く使う方法、そして最初のボスを生き延びるコツを扱います。何年も遅れて始める人も、長い休みから戻ってきた人も、ここで紹介する基本を身につければヤーナムの先へと進んでいけるはずです。

## 始める前に：心構え、生まれ、マインドセット

ブラッドボーンは2015年にPlayStation 4専用タイトルとして発売され、フロム・ソフトウェアが開発、宮崎英高がディレクションを担当しました。ダークソウルとDNAを共有していますが、プレイフィールは大きく異なります。頼りになる盾は存在せず、このゲームは受け身で籠もる戦い方を積極的に罰します。拡張コンテンツ『The Old Hunters』は同年の後半に配信され、今なおやり込み要素の決定版として君臨しています。

もっとも重要なマインドセットの転換はこれです。**死ぬことは失敗ではなく、情報です。** 死ぬたびに、敵のタイミング、ショートカット、あるいは罠を学ぶことになります。熟練プレイヤーはこのゲームを、アクションRPGの皮をかぶったリズム運動だと表現します。各エンカウントのビートを覚え、それに応えて答えるのです。

生まれ（初期クラス）は思っているほど重要ではありません。後からどのステータスでも上げられるからです。それでも、最初の選択が妥当であれば数時間を節約できます。基本ゲームの説明については[PlayStation公式のブラッドボーンページ](https://www.playstation.com/en-us/games/bloodborne/)を読み、そのうえで以下の表を使って選んでください。

| 生まれ | 向いている人 | うまく機能する理由 |
|---|---|---|
| Milquetoast（気弱な男） | 初プレイ | バランスの取れたステータスで弱点なし |
| Lone Survivor（生き残り） | 何度も死ぬことを想定している人 | 初期生命力が最高 |
| Violent Past（乱暴者） | 力特化ビルド | 重い武器が序盤から強烈に決まる |
| Professional（玄人） | 技量特化ビルド | 速い武器と強力な内臓攻撃ダメージ |
| Military Veteran（古参の兵士） | クオリティビルド | 力と技量の均等な配分 |
| Noble Scion（貴族の子弟） | 血質の実験 | 銃器寄りの珍しいステータス構成 |
| Cruel Fate（残酷な運命） | 神秘の実験 | 初期神秘の配分が最良 |
| Troubled Childhood（不幸な幼少期） | 工夫したい人 | 妙なステータス配分。ニッチな選択 |
| Waste of Skin（取るに足らぬ者） | 縛りプレイ | 全ステータスが最低 |

可能なかぎり安全なスタートを切りたいなら、**Lone Survivor**か**Milquetoast**を選びましょう。余分な体力は、余分なダメージよりも多くのミスを許してくれます。

## ヤーナムでの最初の1時間

オープニングのカットシーンが終わると、イオセフカの診療所で目を覚まし、最初の獣に殺され（これはスクリプトされた展開です）、やがて狩人の夢にたどり着きます。このハブがすべての拠点です。武器の強化と修理を行う工房、レベル上げを行う人形、そして物資を保管する収納箱があります。

**出発する前に武器を装備しましょう。** 驚くほど多くの新規プレイヤーが——このゲームに関するもっとも初期のコミュニティ記事の筆者も含めて——工房の使者から武器を受け取ったのに装備せず、素手で何時間も敵を殴り続けてしまっています。近接武器を1つ、銃器を1つ受け取り、インベントリ画面から両方を装備してください。

| 初期武器 | スタイル | 初心者への評価 |
|---|---|---|
| ノコギリ鉈 | 高速、変形、ギザ刃 | 万能型の最適解。獣への追加ダメージあり |
| 狩人の斧 | 重厚、広い振り、長いリーチ | 集団戦に優れ、溜め回転斬りが強力 |
| 仕込み杖 | 優雅、変形で鞭状に | 長リーチだが序盤のダメージは低い。自信のある人向け |

銃器については、**狩人のピストル**が射程の扱いやすい標準的なパリィ用ツールであり、**狩人の散弾銃**は広範囲にばらまき、近距離ならパリィがより寛容に決まります。どちらでも問題ありません。

最初の1時間にやっておきたいこと：

- 見つけたランプはすべて灯す。チェックポイント兼ファストトラベルの拠点になります。
- 木箱や樽を壊す。血の小瓶、水銀弾、小石が隠されています。
- 明かりのついた窓の奥のNPCと話す。何人かは有用なアイテムをくれます。
- ショートカットの門はすべて開ける。ヤーナムのレベルデザインは絶えずループして元の場所に戻ります。
- 血の小瓶は最大20個まで持ち歩ける。余った分は狩人の夢の収納に自動的に送られます。

コミュニティの報告では、最初の1時間がゲーム全体でもっとも難しいパートだと一貫して指摘されています。敵が強いからではなく、まだゲームの語彙を学んでいる途中だからです。

## すべての戦闘を決める戦闘の基本

ブラッドボーンの戦闘は3つの柱で成り立っています。攻撃性、タイミング、ポジショニングです。これらをマスターすれば、難易度のカーブは劇的に平坦になります。

| メカニクス | 効果 | 練習方法 |
|---|---|---|
| ラリー（回復） | ダメージを受けた直後に攻撃すると、失った体力の一部を取り戻せる | 一発食らったら、すぐに振り向いて攻撃 |
| 銃パリィ | 敵の攻撃が当たる直前に発砲すると怯ませられる | セントラルヤーナムのレンガのトロールで練習 |
| 内臓攻撃 | 怯み後の追撃で莫大なダメージ | パリィ後、または溜めバックスタブ後に発動 |
| クイックステップ | 無敵時間付きの回避 | 攻撃から離れるのではなく、攻撃に*向かって*回避する |
| 変形攻撃 | コンボ中に武器の形態を切り替える | 狩人の夢で変形攻撃を練習 |
| ロックオン | カメラを対象に合わせる | 一対一では使う。集団戦では解除する |

ラリーシステムはこのゲームの心臓部であり、多くの新規プレイヤーが無視してしまう要素です。攻撃を受けると体力の一部がオレンジ色になり、じわじわ減っていきます。すぐに攻撃を当てれば取り戻せます。この設計がプレイヤーを前へ押し出し、それはまさにゲームが望んでいることなのです。

パリィには特に注意を払う価値があります。敵の振りが自分に向かって動き始めた瞬間に銃を撃ちましょう。早すぎれば何も起きず、遅すぎれば攻撃を食らいます。**技量**は内臓攻撃のダメージを上げるため、技量ビルドではパリィがボスを消し飛ばす武器になります。

最後に、集団戦は自分のペースで仕掛けましょう。小石を使えば群れから1体ずつ引き剥がせ、扉口は集団を一対一の戦いに絞り込み、階段は敵の隊形を崩します。回避だけを教える**ブラッドボーン初心者ガイド**は役割を果たしていません。ポジショニングは反射神経よりも多くの戦闘を制します。

## 血の残響、ステータス、時間を無駄にしないレベル上げ

血の残響は通貨であり、同時に経験値でもあります。狩人の夢の人形に渡してステータスを上げるか、工房の使者に渡してアイテムを買います。貯めた残響を回収せずに2回連続で死ぬと、その残響は永久に失われます。

実践的なルールはこれです。**大量の残響を抱えたままボス戦に挑まないこと。** 霧の門の前で安全な数値まで使い切り、その後でまた稼ぎ直しましょう。序盤の稼ぎ場所としては、セントラルヤーナムの通りの群衆や、最初のランプ付近にいる2体のレンガのトロールが挙げられます。

| ステータス | 影響するもの | 初心者の優先度 |
|---|---|---|
| 生命力 | 最大HP | 序盤は最優先 |
| 持久力 | スタミナ量 | 2番目の優先度。振りと回避の回数が増える |
| 力 | 重い武器のダメージ | ダメージステータスを1つ選ぶ |
| 技量 | 速い武器のダメージと内臓攻撃ダメージ | ダメージステータスを1つ選ぶ |
| 血質 | 銃器と血の武器のダメージ | 初回プレイでは不要 |
| 神秘 | 狩人用具と属性ダメージ | 初回プレイでは不要 |

序盤の快適な目標は、ダメージステータスを伸ばす前に生命力およそ20、持久力15〜20です。**ブラッドボーンには振り直し（リスぺック）が存在しません**。そのキャラクターのステータス配分は永続なので、何を作りたいのか明確でない限り、血質や神秘にポイントを散らすのは避けましょう。

武器の強化も忘れずに。血石の欠片はセントラルヤーナム各地に散らばっており、工房での強化のたびにダメージが目に見えて上がります。耐久値のメーターが減ったら工房で修理しましょう。

## ボス、協力プレイ、そして最初の本当の壁

ほとんどのプレイヤーが最初に出会うボスは聖職者の獣で、これは任意ボスです。ただし倒せば啓蒙を得られ、召喚用の呼び鈴が解放されます。真の関門は、橋の上での必須戦であるガスコイン神父です。コミュニティでは彼をこのゲームのフィルターボスと呼びますが、それも当然でしょう。距離を罰し、素早く間合いを詰め、第2フェーズでは獣へと変身します。

| よくあるミス | より良いアプローチ |
|---|---|
| 通りの敵すべてと正面から戦う | 小石で1体ずつ引き剥がす |
| 血の残響を溜め込む | ボス戦の前に人形で使う |
| 血の小瓶が尽きる | 序盤の群衆から稼ぎ、まとめ買いする |
| 武器強化を無視する | 工房で血石の欠片を使う |
| パニックで攻撃から離れる方向に回避する | 攻撃に向かって、すり抜けるように回避する |
| NPCの会話を飛ばす | 明かりのついた窓では2回話しかける |

協力プレイは正攻法であり、松葉杖ではありません。**呼び鈴**は啓蒙を1つ消費して助っ人を呼び出し、**共鳴する小さな鐘**を使えば他人の世界に参加して無料で練習でき、余分な残響も得られます。啓蒙はボス、狂人の知恵、そして新しいエリアに足を踏み入れるだけでも手に入ります。

血に飢えた獣を倒すと、聖杯ダンジョンが開放されます。より多くの戦利品と厳しい戦いを求めるプレイヤー向けの、任意の自動生成コンテンツです。本編に慣れてから挑みましょう。

## よくある質問

**ブラッドボーンは初心者に優しいですか？**
最初は優しくありませんし、それは意図的なものです。防御的な習慣を捨てることを求めてきますが、ラリー、パリィ、ポジショニングが噛み合えば——たいてい数時間以内に——史上もっとも満足感の高いアクションゲームのひとつになります。このブラッドボーン初心者ガイドが存在する理由は、まさにゲームの序盤がもっとも険しいからです。

**先にダークソウルをプレイする必要がありますか？**
いいえ。ブラッドボーンは独自のシステムを持つ単体のゲームであり、ここから始めたプレイヤーも多くいます。ソウル系の経験は忍耐や敵の予備動作の読みに役立ちますが、攻撃的な戦闘ループは独特です。

**初めてのプレイヤーはどの生まれを選ぶべきですか？**
体力を重視するならLone Survivor、バランスならMilquetoast。Waste of SkinとTroubled Childhoodは、自分が何をしているか分かってからにしましょう。

**後からステータスを振り直せますか？**
いいえ。ブラッドボーンに振り直しシステムはないので、ビルドは計画的に。ダメージステータスを1つ——力か技量——選び、残りは生命力と持久力に回しましょう。

**初回プレイにはどれくらいかかりますか？**
多くのプレイヤーはおよそ30〜40時間でクリアします。任意エリアや聖杯ダンジョンを探索すればもっと長くなります。拡張『The Old Hunters』は、ゲーム内でもっとも難しいコンテンツをさらに数時間分追加します。

要するに、攻撃的に立ち回り、残響は使い切り、武器を強化し、すべての死を教訓として扱うこと。それが成功する**ブラッドボーン初心者ガイド**の哲学そのものであり、 frustrate した新参者から自信ある狩人へと至る最短ルートです。
